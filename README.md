## 🖼️ Adding Your Profile Photo & Resume

### 1. Profile Photo
- Copy your photo into the `assets/` folder and name it `profile.jpg` (`assets/profile.jpg`).
- The website will automatically render your photo within the circular frame with subtle glow.

### 2. Resume PDF
- Copy your PDF resume into the `assets/` folder and name it `resume.pdf` (`assets/resume.pdf`).
- Clicking **Download Resume** anywhere on the website will trigger the PDF download.

## 🌐 Deploying to GitHub Pages (Free Hosting)

1. Create a repository on GitHub named `shijithajenifer.github.io` (or `portfolio`).
2. Push the files in this folder to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/shijithajenifer/portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** > **Pages** > Select `main` branch > Click **Save**.
4. Your website will be live in 1–2 minutes at `https://shijithajenifer.github.io`!
